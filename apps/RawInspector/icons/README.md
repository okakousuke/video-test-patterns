# ダッシュボードのアイコン

最初の画面（`DashboardView.xaml`）で使う 128px の PNG です。

## 絵文字をやめた理由

絵文字はフォント任せなので、環境によって形も色も変わります。
Windows の版が違えば別の絵になり、フォントが無ければ豆腐になります。
画面の意味を絵で伝えるつもりなら、絵をこちらで持つ必要があります。

## 出どころ

画像生成（Grok）で作った元絵から切り出したものです。
元のシートは `qiita-articles/assets/images/diagrams/映像テストパターン生成器シリーズ/pat*.jpg` にあります。

切り出しでやったこと。

1. シートを区画へ分け、地の色と違う画素の外接矩形で各アイコンを取り出す
2. 地の色からの距離でアルファを作って透過へ抜く（0/1 で切ると輪郭が階段になります）
3. 正方形の中央へ置いてから 128px へ縮める（縦横比が違うと並べたとき大きさが揃いません）

## 大きさ

**表示は 44px です。** 32px より下にすると、格子の目・時計の針・歯車の歯が
灰色に潰れて意味が読めなくなります。実際に 26 / 32 / 44 / 48px で並べて確かめました。

128px で持っているのは、高DPI で 2 倍になっても足りるようにするためです。

## 対応

| ファイル | 使う場所 |
| --- | --- |
| `generated.png` | `generated/`（破線の枠＝使い捨て） |
| `samples.png` | `samples/raw/`（実線の枠＋しおり＝残すもの） |
| `recent.png` | 前回開いていた場所（時計） |
| `gen-ok.png` | 生成器へ繋がっている（歯車＋緑の✓） |
| `gen-ng.png` | 生成器へ繋がらない（同じ歯車＋赤の！） |
| `patterns.png` | 全パターンを1本ずつ（違う絵柄のタイル） |
| `variants.png` | 条件を振って量産（1つの絵柄→多数） |
| `storage.png` | 格納形式を網羅（区画の違う板の重なり） |

`gen-ok` と `gen-ng` は**同じ歯車でバッジだけ違います**。並べたときに
どちらの状態かが形で分かるようにするためです。
