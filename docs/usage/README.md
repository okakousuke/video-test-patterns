## この文書の置き場所

実体はリポジトリの `docs/usage/` にあります。ビルドすると実行ファイルの隣へ複製されるので、
リポジトリを持っていない人へビルド結果のフォルダごと渡しても、そのまま読めます。

アプリは次の順で探し、先に見つかったものを出します。

1. リポジトリの `docs/`
2. 実行ファイルの隣の `docs/`
3. 実行ファイルへ埋め込んだもの（1も2も無いとき）

リポジトリを先に見るのは、そちらが実体で、実行ファイルの隣にあるのはビルド時の複製だからです。
文書を直しながら動かしているときに、古い複製のほうが出ると混乱します。
いまどれを読んでいるかは、使い方の窓のいちばん下に出ています。
