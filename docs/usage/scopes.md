# 分布で見る

ツールバーの **「📊 分布…」**（`F7`）で開きます。RAWを1本選んでいると押せます。

絵を眺めても分からないことがあります。**1コード値だけずれている**、
**上のほうが少しだけ潰れている**、**使われている階調が思ったより少ない**。
かといって画素を1つずつ拾って回るわけにもいかないので、**全画素を数えて**分布にします。

絵と並べて見られるよう、本体とは別の窓で開きます。本体の操作は止まりません。

## 何をどの条件で数えたか

窓のいちばん上に、**どのRAWを・どの条件で数えたか**が出ます。
分布そのものより先にこれが目に入る位置に置いてあります。
別のRAWの数字を、いま見ているRAWのものだと読むのがいちばん危ないためです。

集計に効くのは **matrix・range・色差の戻し方**だけです。
**成分の選択と段は効きません。** ここで見たいのはRAWに入っている値そのものであって、
いま画面に出している絵ではないからです
（Y' だけを表示している状態で分布を見て、それをRAW全体の分布だと読むと間違えます）。

## 自動では数え直しません

4K なら1回で 800 万画素を1周します。一覧を矢印キーで送るたびに走らせると、
本体の操作まで重くなります。そこで**数え直しは「⟳ 取り直す」（`F5`）を押したときだけ**です。

黙って古い数字を出し続けるのは、それより悪い状態です。本体で別のRAWが選ばれたり、
matrix や range が変わったりしたときは、**窓の上に警告が出ます。**

## ヒストグラム（コード値の分布）

横がコード値、縦がその値を持つ画素の数です。**表示用の8bitではなく、RAWのコード値のまま**数えています。
10bit のRAWなら 0–1023 のままです。

細い縦線は規定の範囲（limited のときの 16 と 235／240）の境目です。
`limited` と記録されたRAWで、この線の外に山があるなら、それは規定の外の値が入っているということです。

**縦は既定で対数です。** テストパターンは一様な面を持つものが多く、そこだけ何万画素も積み上がります。
線形の目盛りだと、その山以外は床に貼り付いて見えません。
「1画素だけ違う値がある」を見つけたいので、既定を対数にしています。線形にも切り替えられます。

## 波形（横位置ごとの分布）

横が画像の横位置、縦がコード値です。明るいところほど、その位置にその値の画素が多くあります。
どの成分を出すかは選べます。

- 横は、幅が 512 を超えると**何画素かを1列に束ねます**（4K をそのまま出すと画面に入りません）。
  束ねた列数は窓に出ます。細い縦線は隣と混ざります
- 縦は 256 段です。10bit のRAWでもここへ束ねます

横線は規定の範囲の境目です。ランプやグレースケールのパターンで、
**どこから潰れはじめているか**がここに出ます。

## ベクトル（Cb-Cr 平面）

横が Cb、縦が Cr です。中心（128, 128）が無彩色で、外へ行くほど色が濃くなります。

小さな印は、**いまの matrix と range で計算した**原色・補色（R・Y・G・C・B・M）の位置です。
規格の図版は持っていません。その場で計算しています。

- カラーバーの点がこの印に乗っていれば、その matrix で読むのは正しい
- 印から回転してずれていれば、matrix を取り違えている

Y'CbCr のときだけ出ます。RGB には色差がないので、この平面に置く意味がありません。

## 数値

| 欄 | 何が分かるか |
| --- | --- |
| 値の幅 | 実際に出てきたコード値の最小と最大 |
| 平均 | 全画素の平均 |
| 値の種類 | 実際に出てくるコード値が何種類あるか。**階調の粗さ**がここに出ます |
| 規定の範囲 | limited のときだけ内側になります（輝度 16–235、色差 16–240） |
| 規定外の画素 | その範囲の外にある画素の数。`limited` のRAWでここが 0 でないことには意味があります |

下の枠には、**変換後に 0-1 の外へ出る画素の数**が出ます。
プレビューの「範囲外」で色が付く画素と同じ数え方です（数と色が食い違わないよう、判定は1か所です）。
ここに出る画素は、画面へ出すときに丸められるので、元の値へは戻せません。

## 読み方の例

- **`limited` のRAWなのに、規定外の画素が 0 でない** — 生成側が規定を守っていないか、
  もともと規定外を含む素材です。どちらなのかはヒストグラムの山の位置で見当が付きます
- **値の種類が極端に少ない** — 階調が量子化で潰れています。ランプやグレースケールで起きていれば、
  そのRAWは階調の確認には使えません
- **ベクトルの点が印から回転している** — matrix を取り違えています。
  本体で matrix を切り替えて、点が印に乗る組み合わせを探せます
- **変換後に 0-1 の外へ出る画素がある** — 形式と絵の組み合わせで起きることもあります。
  `hatch_redblue` を 4:2:0 で持つと、記録どおりに読んでも半分の画素が下へ外れます
  （1画素おきの赤と青が、間引きで1種類の色差に潰れるためです）
