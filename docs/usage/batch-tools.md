# スクリプトを走らせる

[ホーム画面](launcher.md)の下段です。**画面は開きません。**
押すとその場でPythonのスクリプトが動き、結果は下の「スクリプトの記録」に出ます。

まとまった数のファイルができます。数百MBになるものがあるので、押す前にここを読んでください。

## 3つの道具

目的が違うので分けてあります。同じ「RAWを量産する」でも、あとから見るものが違います。

| 道具 | 何のためか | できる量 | 先に数える |
| --- | --- | --- | --- |
| 全パターンを1本ずつ | パターンの一覧そのものを目で見る | 42本ほど / 数十MB | — |
| 条件を振って量産 | 同じパターンが条件でどう変わるかを見る | 百数十本 / 数百MB | あり |
| 格納形式を網羅 | 絵を固定して、形式ごとの違いだけを見る | 20本ほど / 数MB | — |

### 全パターンを1本ずつ（`tools/make_samples.py`）

42パターンを1本ずつ作ります。格納形式と寸法はパターンごとに変えます。

サイズを1つに揃えないのは、幅や高さに依存する不具合（行のまたぎ、色差面の端数、
パック単位の切り上げ）を丸い数字で隠さないためです。割り当ては乱数で決めますが、
**シードを固定**しているので毎回同じ結果になります。

実際この一式を作ったことで、YCbCr planar の 4:2:0 がプレビューできないという穴が見つかりました。

### 条件を振って量産（`tools/make_variant_raws.py`）

1つのパターンを条件で振ります。3つの群があります。

| 群 | 内容 |
| --- | --- |
| `raster` | 一様な塗りを15色ぶん。合わせて同じ塗りを 4:4:4 / 4:2:2 / 4:2:0 で出します |
| `cards` | カラーバー・放送系カードを、規格の解像度ぶん。形式は固定なので違いはサイズだけです |
| `resolution` | 解像を見るパターンを、サイズと格納形式の両方で振ります |

`raster` の3本は**同じ結果になるはずのもの**です。一様な面には色差の細かい変化が無いので、
どの間引きでも一致します。差が出たら、それは間引きの損失ではなく色変換かビット詰めの誤りです。

これだけが「先に数える」を持ちます。作らずに、何本できて何MBになるかだけ出します。

### 格納形式を網羅（`tools/make_reference_raws.py`）

絵とサイズを固定して、planar / packed / NV12 / P010 / v210 / MIPI10 などを一通り出します。
絵が同じなので、読み手側の実装で崩れたときに、形式の解釈だけが原因だと切り分けられます。

既定は 192×144 と小さめです。リポジトリへ同梱するものなので容量に収めています。

## 出力先

| 道具 | 既定の出力先 |
| --- | --- |
| 全パターンを1本ずつ | `generated/` |
| 条件を振って量産 | `generated/` |
| 格納形式を網羅 | `samples/raw/` |

`generated/` は `.gitignore` の対象で、リポジトリには残りません。作って捨てる場所です。
`samples/` はリポジトリへ同梱するもので、役割が違います。

## 端末から使う

ホーム画面のボタンは、オプションなしで実行しているだけです。
細かく指定したいときは端末から呼んでください。

```sh
python tools/make_samples.py --out DIR          # 出力先を変える
python tools/make_samples.py --seed 123         # 別の割り当てにする
python tools/make_samples.py --max-pixels 8294400   # 4K まで使う

python tools/make_variant_raws.py --group cards # 群を選ぶ
python tools/make_variant_raws.py --dry-run     # 何を作るかだけ表示

python tools/make_reference_raws.py --size FHD --out generated
```

## 実サイズは容量に注意

`make_reference_raws.py` で実サイズを指定すると、20形式ぶんの合計は次のようになります。

| サイズ | 合計 |
| --- | --- |
| small（192×144、既定） | 数MB |
| HD（1280×720） | 57MB |
| FHD（1920×1080） | 128MB |
| 4K（3840×2160） | 511MB |

実サイズで見たいときは `--out generated` を付けてください。リポジトリに入れる大きさではありません。

ファイル名にサイズは入りません。形式ごとの違いだけを見るためのものなので、
同じ場所にサイズが混ざるほうが困るためです。**同じ出力先へ別のサイズを出すと上書きになります。**

## 走らせた後

ホーム画面の件数は自動で数え直します。できたものは「素材のある場所」の `generated` から開けます。
見方は [RAWを見る](viewer.md) へ。
