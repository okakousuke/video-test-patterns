# ホーム画面

起動すると最初に出る画面です。ツールバーの「🏠 ホーム」でいつでも戻れます。
戻っても、読み込んだ一覧は消えません。

## ここに出るもの

**起動するだけの入口にはしていません。** それだと `--help` を写しただけのものになり、
道具が増えるたびに更新漏れで古くなります。ここに出すのは、道具を1つずつ叩いても分からないことです。

- 素材がどこに何件あって、読めないものが無いか
- 生成器（Python側）へ繋がっているか
- 一括生成を、作る前に件数と容量を見てから走らせられるか

## 3つの区分

押した先に画面が出るのか、黙ってスクリプトが走るのかは、押す前に分かる必要があります。
**カードの左端の色帯と、カードの形**で分けています。

| 区分 | 押すとどうなるか | 帯の色 | 形 |
| --- | --- | --- | --- |
| 画面で操作する | 窓が開きます。そこから先は手で操作します | 青 | 幅いっぱいの帯を縦に積みます |
| 素材のある場所 | そのフォルダを一覧へ読み込みます | 青 | 幅いっぱいの帯を縦に積みます |
| スクリプトを走らせる | 画面は開かず、その場でPythonが動きます | 緑 | 四角い札を横に並べます |

色帯だけで分けると、走らせてから「画面が出ない」と気付きます。
スクリプトのほうは四角い札にして横に並べ、形の段階で別の種類だと分かるようにしています。
札は高さを揃えてあるので、件数・容量と「実行」の位置がどれも同じところに来ます。
札に収まらない説明は途中で「…」になります。**全文は札の上にカーソルを置くと出ます。**
窓を狭めると、札は2枚ずつ・1枚ずつに折り返します。

「画面で操作する」は2つです。

- **RAWを見る** — フォルダを開いて1本ずつ確かめます。詳しくは [RAWを見る](viewer.md)
  押すと、開く場所を訊く窓が出ます。**選ぶのはフォルダ**ですが、中の
  `*.manifest.json` が見えるので、開く前に行き先が合っているか確かめられます。
  目的のフォルダまで入って、何も選ばずに「開く」を押してください。
  開く先がまだ決まっていないときの窓なので、場所が決まっているなら
  下の「素材のある場所」から押すほうが早く、選択の窓は出ません。
  選ぶのをやめれば、このホーム画面に残ります。
- **パターンを作る** — 条件を選んで1本作ります。詳しくは [パターンを作る](generator.md)

「スクリプトを走らせる」は3つあり、まとまった数のファイルができます。
実行の前に [スクリプトを走らせる](batch-tools.md) を読んでください。

## 素材の件数の読み方

件数だけでなく、**読めないものの数**も出します。
「190件あります」より「190件のうち2件が読めません」のほうが、次にやることが決まるためです。

読めないものに数えるのは次の2つです。

- manifest として読めなかったもの（JSONが壊れている、`manifest_version` が 1 でない）
- manifest は読めたが、`files[].path` の指すRAWが見つからないもの

右上の「数え直す」で走査し直します。フォルダの中身をアプリの外で入れ替えたときに使ってください。

出るフォルダは役割で分けています。

| フォルダ | 役割 |
| --- | --- |
| `generated` | 作って捨てる場所です。`.gitignore` の対象で、リポジトリには残りません |
| `samples/raw` | リポジトリに同梱している参照用です。読み手側の実装の入力テストにそのまま使えます |
| 前回開いていた場所 | 前回このアプリで開いていた場所です。上の2つと同じなら出ません |

## 生成器の状態

**画素を作るのはPython側の生成器です。** このアプリは条件を渡して呼ぶだけなので、
繋がらなければ生成はできません。繋がらないことに気付くのが「生成の窓を開いたとき」だと遅いので、
入口のすぐ下に出しています。

繋がっているときは、生成器が申告してきた内容がそのまま出ます。

```text
video-test-patterns 0.1.0　パターン 42 種 / 成立する組み合わせ 62 通り / 格納形式 6 種
```

繋がらないときは、**読み込みと表示はこのままできます。生成だけができません。**
次を確認してください。

```powershell
pip install -e ".[dev]"   # リポジトリのルートで
python -m vtp --describe  # これが JSON を返せば繋がります
```

`python` にPATHが通っているかも確認してください。
呼び出すコマンドは生成の窓の「生成器の呼び出し方」欄で変えられます（既定は `python -m vtp`）。

## リポジトリが見つからないとき

画面のいちばん下にリポジトリの場所が出ます。ここが「見つかりません」のときは、
素材フォルダの表示と一括生成が使えません。

場所は、実行ファイルから上へ辿って探しています。目印は `pyproject.toml` と
`src/vtp/patterns.py` の**両方がある**場所です。相対の段数を決め打ちすると、
出力先を変えただけで見失うためです。実行ファイルだけを別の場所へ置くと見つかりません。

その場合でも、ツールバーの「📁 フォルダを開く」で場所を指定すれば、RAWの表示はできます。
