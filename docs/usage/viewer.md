# RAWを見る

manifest とRAWの入ったフォルダを開いて、1本ずつ確かめる画面です。

## フォルダを開く

ツールバーの「📁 フォルダを開く」（`Ctrl+O`）で指定します。サブフォルダも走査します。
[ホーム画面](launcher.md)の「素材のある場所」から開くこともできます。

出るのは**ファイルを選ぶ窓**で、`*.manifest.json` が見えるようにしてあります。
選ぶのは1本ですが、読み込むのは**そのファイルのある親フォルダ**です。
フォルダを選ぶ窓（`OpenFolderDialog`）は仕様上ファイルを一切表示しないので、
中身を見ないまま「ここで合っているはず」と押すことになります。
manifest が見えれば、開く前に行き先が正しいかを確かめられます。

`*.manifest.json` を探し、そこに書かれた `files[].path` からRAWを引きます。
RAWだけを置いたフォルダは開けません。**RAWには寸法も色形式も入っていない**ので、
manifest が無いと読み方が決まらないためです（[manifest v1 共通仕様](../manifest-v1.md)）。

開いたまま作り直したときは `F5` で読み直します。選んでいたRAWと表示倍率はそのまま残ります。

## 一覧を絞る

パターン名ごとにまとまって並びます。左上の `⊟` `⊞` でまとめて閉じる／展開できます。

| 絞り込み | 内容 |
| --- | --- |
| 色モデル | RGB系かY'CbCr系か |
| サイズ | 先頭に「〜HD」「〜FHD」「〜4K」「4K超」の粗い区分。その下に実サイズ |
| パターン | パターン名で1種類に絞ります。並ぶのは開いているフォルダに実際にあるものだけです |
| 比 | 画素数の比です。16:9 のものだけを見比べたいときに使います |

絞ったまま「件数が合わない」と悩まないよう、「解除」で全表示に戻せます。

並び順は名前順と解像度順（小さい順／大きい順）です。名前順だと `1280x720` が `176x144` より
前に来ます（文字として比べるためです）。解像度順は**画素数**で比べるので、
`1280x720`（92万）→ `1366x768`（105万）→ `1280x1024`（131万）のように、
幅だけでは決まらないものも正しく並びます。見出し（パターン名）は常に名前順です。

赤い文字の項目は読めなかったものです。選ぶと理由が出ます。

## 画面に出ているのはRAWそのものではありません

ここがいちばん誤解しやすいところです。**プレビューは変換の結果**です。
そのため画面の右下に、いま見えている絵をどう作ったのかを毎回出しています。

```text
1. 格納形式 nv12 から Y' / Cb / Cr のコード値を取り出す（8bit: 0-255）
2. 間引かれた色差を輝度と同じ密度へ戻す（4:2:0 / 最近傍）
3. range=limited として正規化する
4. matrix=bt709 でRGBへ戻す
5. 0-1 に丸めてから 8bit（0-255）へ量子化し、画面へ出す
```

画面の上に出る「RAWの条件」がデータそのものの条件、右下が絵の作り方、という対応です。

## 表示条件を変えて見比べる

**RAWには一切触りません。読み方だけを変えます。**

| 切り替え | 何が分かるか | 出る条件 |
| --- | --- | --- |
| 成分（Y'・Cb・Cr または R・G・B） | 選ばなかった成分を中立値に置き換えて見ます。色差だけ・輝度だけを取り出せます | 常に |
| コード値 | 色変換を通さず、コード値をそのまま濃淡にします。面の値をそのまま読めます | 成分を1つだけ選んでいるとき |
| matrix（bt601 / bt709 / bt2020） | 別の係数で戻したときの色ずれを見ます | Y'CbCr のとき |
| range（full / limited） | 取り違えたときの黒浮き・白のくすみを見ます | Y'CbCr のとき |
| 色差の戻し方（最近傍 / バイリニア） | 間引かれた色差の戻し方で見え方がどう変わるかを見ます | 色差が間引かれている形式のとき |

初期値はmanifestの記録どおりです。**違う条件にしている間は画面に警告が出ます。**
条件を変えたことを忘れると「RAWが壊れている」と読み違えるためです。「戻す」でmanifestの条件へ戻ります。

成分は排他ではなく、組み合わせて選べます。選ばなかった成分は**中立値に置き換えてから**変換します
（コード値をORしても意味のある数にならないためです）。

- **Cb + Cr（Y'を外す）** — 輝度が中立に固定され、色差だけが残ります。白バーと黒バーが同じ明るさになります
- **Y' だけ** — 色差が中立に固定され、どの色バーも無彩色になります
- **どれも選ばない** — 全面が中立値になり、平坦な絵になります

使えない条件のグループも場所だけは残ります。詰めてしまうと、選んだRAWによって
他のボタンの位置まで動き、同じ場所を押しているつもりで違うものを押すことになるためです。

## 画素の値を読む

カーソルを乗せると、下のバーに座標・生のコード値・変換後のRGBが出ます。
右クリックでコピーのメニューが出ます。**実際にコピーされる文字列がそのまま並びます。**

| 項目 | 何の値か | 範囲 |
| --- | --- | --- |
| 生コード値 | RAWのバイト列から取り出した値。変換していません | 8bitなら 0–255、10bitなら 0–1023 |
| HEX / RGB値 | matrixとrangeを適用し、8bitへ丸めた表示用の値 | 常に 0–255 |
| 座標 | 左上が (0, 0) | |
| まとめて1行 | 上をまとめたもの。記事やテストコードへ貼るとき用 | |

プレビュー画像そのものは RGB888 です。10bitのRAWでも画面に出る時点で8bitへ落ちています。
階調を落とさずに見たいときはコード値のほうを読んでください。

4:2:0 / 4:2:2 の Cb・Cr は、**その画素が共有している間引き後のサンプル**をそのまま返します。
隣り合う2画素や4画素で同じ値が出るのは、色差がそこにしか無いためです。

## 拡大して形を確かめる

倍率は 10〜1600% です。上を厚くしてあるのは、ここで見たいものが1画素の単位で決まっているためです。
1画素の縞は100%では画面の1点にしかならず、出ているかどうかを目で確かめられません。

**縮小には注意が要ります。** 100%未満では最近傍で間引くので、1画素の線や点は画面から消えます。
RAWから無くなったわけではありません。100%未満のときは絵の作り方の欄にその旨が出ます。

「格子」は画素の境目に線を引きます。隣り合う画素が同じ値だと境目は見えないので、
「1画素の線」なのか「2画素の帯」なのかは線を引いて初めて数えられます。
色差が間引かれている形式では、**同じ色差を共有する範囲**の枠を太く重ねます
（4:2:0 なら 2×2、4:2:2 なら 2×1、4:4:4 なら枠なし）。600%以上で使えます。

操作モードは3つで、PDFビューアと同じ考え方です。

| モード | ドラッグ | ホイール |
| --- | --- | --- |
| ↖ 選択（既定） | — | 通常のスクロール |
| ✋ 移動 | 表示位置を動かす | 通常のスクロール |
| 🔍 拡大鏡 | — | 拡大縮小（Ctrl不要） |

`Ctrl`+ホイールはどのモードでも拡大縮小なので、モードを切り替えなくても拡大できます。
ボタンとキーは**表示領域の中央**を固定し、`Ctrl`+ホイールだけは**カーソル下の画素**を固定します。

## 保存する

| 操作 | 出るもの |
| --- | --- |
| 形式を選んで「保存…」 | 選んだ1形式。保存先とファイル名を指定します |
| 「全形式」 | PNG・JPEG・TIFF・BMP・GIF をまとめて出力先フォルダへ |
| 「💾 RAWコピー」 | 選択中のRAWを、変換も圧縮もせずそのまま |

保存すると、**manifestと違う条件にしていたときだけ**名前に条件が残ります。
同じRAWから何枚も出すので、名前が同じだと後から見分けが付かず、上書きも起きるためです。

```text
既定のまま        colorbar_ycbcr420_8bit_nv12.png
matrix を変える    colorbar_ycbcr420_8bit_nv12_bt601-limited.png
Y' だけにする      colorbar_ycbcr420_8bit_nv12_bt601-full-Y.png
```

**RAWコピーには付きません。** 表示条件を変えてもRAWのバイト列は変わらないためです。
`_bt601` の付いたRAWがあると「bt601へ変換したRAW」に見えますが、そんなものは作っていません。

## キー操作

| キー | 動作 |
| --- | --- |
| `Ctrl+O` | フォルダを開く |
| `F5` | 開いているフォルダを読み直す |
| `Ctrl+0` | 等倍（100%）に戻す |
| `Ctrl` + `+` / `-` | 表示倍率を1段階変える（表示領域の中央を保つ） |
| `Ctrl` + ホイール | 表示倍率を変える（カーソル下の画素を保つ） |
| `F11` / `Esc` | プレビューの全画面に出入りする |
| 右クリック | 指した画素の値をコピーするメニュー |
| `Ctrl+1`〜`Ctrl+5` | PNG / JPEG / TIFF / BMP / GIF で保存 |

## うまくいかないとき

| 症状 | 見るところ |
| --- | --- |
| 一覧に何も出ない | フォルダに `*.manifest.json` があるか。RAWだけでは開けません |
| 赤い文字で並ぶ | manifest が壊れているか、`files[].path` の指すRAWが無い。選ぶと理由が出ます |
| プレビューが出ない | 未対応の格納形式です。manifest の内容と理由は表示されます |
| 絵が斜めに崩れる | manifest の `width` / `height` が実際と違います。行の境界がずれると全体が斜めになります |
| 色がおかしい | matrix / range をmanifestと違う値にしていないか。違うときは画面に警告が出ます |
| 赤と青が入れ替わる | packed 形式の成分順（`channel_order`）です |
| 細い線が見えない | 100%未満では間引きで消えます。等倍以上にしてください |
